# Reference principles · original adaptation

Issue #55 names category leaders as quality references. This is a conceptual analysis of their interaction principles, not a new hands-on competitive benchmark. No competitor screenshots, artwork, logos, layout code, sounds or proprietary sprites are copied. Every new illustration is authored in build-concepts.py or the HTML/CSS sources.

| Reference category | Useful principle | Original Playgrid adaptation |
|---|---|---|
| [Gartic](https://gartic.io/) / [skribbl](https://skribbl.io/) | Protect the canvas; private prompt; nearby readable live guesses | Warm Sketch Club paper, original dragon example, thin tool rail and full phone palette. Existing Playgrid drawing model and privacy stay intact. |
| [Gartic Phone](https://garticphone.com/) | Separate current task from the delight of final chain reveal | Coral Paper Relay studio and numbered paper spine. Only the current source appears during work; full reveal timeline waits for Stage B. |
| [Kahoot](https://kahoot.com/) | Strong question hierarchy, fast large choices, distinct lock/reveal | Orbit Quiz jewel panels with numbered circular keys, not copied proprietary choice symbols or brand styling. |
| Polished word applications | Tactile letter forms, clear typing rhythm, stable input focus | Letterworks ivory rack, Chain Reaction linked history, Fieldbook private form. No copied tile logos, Wordle rules or unrelated scoring. |
| Premium physical tabletop games | Legible ownership, convincing object materials, quiet surrounding UI | Original cobalt Drop Society cabinet, ceramic Cross & Circle board, stitched Dots patches, jade Checkers inlay. Rules and exact coordinate systems remain Playgrid’s. |
| Social deduction / bluffing games | Equal anonymous options, explicit phase, hidden private knowledge | Velvet Lie ballots and Confidential Club private folder/public ledger. No popularity hints or role tells before authorized reveal. |
| Tournament games | Readable bracket with a clear immediate duel | Throwdown hand art and compact mobile bracket; no fabricated throws, new confirmation or take-back phase. |

Playgrid remains Playgrid: existing navy/lime brand, mark, Inter and portraits. Individual game surfaces use their own material palette so the collection feels designed rather than covered by one CSS skin.
