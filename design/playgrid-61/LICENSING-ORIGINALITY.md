# Originality and reuse inventory

This package contains authored editable SVG/code and project-asset reuse. No stock-character service, copied franchise character, paid generation API, image-only character mockup or external image URL was used.

| Material | Origin | Treatment / counting |
|---|---|---|
| Existing home hero / player portraits / mark | Owner-supplied existing Playgrid repository assets | Reused unchanged as canonical reference, classic choices and branding. No claim that this assignment authored or re-licensed these raster assets. |
| a01–a32 layered bases | Original Issue #58 commissioned vector designs at f478a1e, refined here | Same 32 additional bases; stable IDs, new revision2. Not counted again as 32 new inventions. Anatomy/material/expression deltas are in build-avatars.py. |
| h01–h03 foundation studies | New editable reinterpretations of Playgrid’s three existing home archetypes | Not counted as additional characters. These do not replace the exact painted hero. |
| Default-look SVGs / 24,32,48,128 PNGs | Deterministic composition/render of those sources | Exports/variants, not additional bases. No raster painting or unrelated stock substitute. |
| Minimal robot fallback | New compact original SVG in this package | Utility asset, outside character count. No external resource. |
| Stack/marine card backs and fish engraving | Already-approved original eight-game artwork at 87d8b35, portable subset retained in #58 | Three small SVG excerpts reused unchanged in component references, not presented as new art or a new game direction. |
| Prior comparison SVGs a02/a13/a19 | Unmodified Issue #58 original sources | Three labeled before/after excerpts only; the old full package is not duplicated. |
| Pool cue/cloth / safe-cell fragment / Golf loupe | New SVG/DOM component examples in game-feel/feel.js | Palette/material compatible with approved games; source geometry/rules are unchanged. Not full replacement game boards. |
| Inter font | Existing bundled project font | Existing SIL Open Font License retained at node-server/public/assets/fonts/OFL.txt. |
| Fixtures | Offline output of existing local game modules at 06609a4 from arranged local states | Synthetic names/IDs/positions; not private player data or evidence of full matches. |

`ORIGINALITY.csv` records each base and its silhouette distinction. `ASSET-MANIFEST.json` records exact files, bytes, SHA-256, source role and source commits. Palette, expression and accessory variants are never used to inflate the base count.

Use the new commissioned source for Playgrid under the project’s applicable ownership/licensing arrangement. This package does not invent a public third-party license for the owner’s existing branding or illustrations. No new third-party art attribution is required by a new stock asset because none was introduced. Exact painted-style fidelity still needs visual owner review; originality and structural validation do not establish a perfect style match.
