# Ludo · Toybox Royale

**Approved creative direction. Implement using [the shared handoff](../IMPLEMENTATION-HANDOFF.md).**

## Identity

Lacquered numbered discs, pale inset home wells and a substantial ivory die. A cheerful tabletop toy.

## Composition

Large board with players at its corners. Desktop die/choices sit to one side; tablet and phone use a compact low die pod with legal-token alternatives.

## Interaction boundary

Retain four token identities and exact tracks. Die shows server value; legal token buttons mirror the board. The concept shows four choices after a six, not a fabricated single legal move. Stacks/safe squares need accessible markers in implementation.

## Motion story · intent, not final specification

Server value settles in die → accepted token travels along the real route → capture/home stamp; bonus roll is stated in words.

## Required implementation states

Waiting, rolling, choosing, token travel, capture, safe/stacked tokens, no legal move, six bonus, triple-six forfeiture, home/win, disconnect.

## Approved direction

Approve toy materials and perimeter seating. Never infer a roll, landing or capture from an animation.
