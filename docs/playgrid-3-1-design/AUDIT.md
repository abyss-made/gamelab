## Shared findings

1. **Highest leverage:** larger contextual feedback, stable local controls and recognizable materials, rather than lime on every playable object.
2. **Dense phone exceptions:** Chess/Checkers need full-width squares; Ludo needs a token list alternative; Battleship needs full-width active grid plus explicit confirmation. Never shrink an entire desktop layout to fit.
3. **Phase 2 guardrails:** keep the widened drawing canvas and all palette colors; do not reintroduce clipping or guesser tools. Preserve the fill optimizations, persistent sizes, long-name/clue wrapping, done locks, and idle/scoring corrections.
4. **Not visually resolvable:** timer-Off stall (#42), DOM replacement/focus and resign confirmation (#43), fleet locking/out messages/filler (#44). The proposal specifies UI states without asserting that these behavior changes have shipped.
