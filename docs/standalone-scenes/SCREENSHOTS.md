# Actual screenshot index

[Interactive comparison viewer](index.html) supports one game at a time or all ten, three viewport sizes, played states, results and reference images. On GitHub, use the PNG links below; HTML opens as source there. Run `python -m http.server 45410 --directory docs/standalone-scenes` locally to use the viewer.

Before = previous visual revision **600d87b**. After source = **5fa1639**. All PNGs come from the actual application. Random deals/turns vary. Pool after uses the real shooter with cue-ball placement locked. Images are viewport captures, so vertical scrolling can reveal more controls/content.
