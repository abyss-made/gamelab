# Reference and asset provenance

Reference: **Mini Golf Club**, Obumo Games — https://minigolfclub.io/ (equivalent publisher homepage: https://www.minigolfclub.io/).

The publisher's gameplay image informed raised stone borders, textured turf, water surroundings, physical obstacles and the angled course-first presentation:

- [Publisher gameplay image](references/gameplay.png): https://minigolfclub.io/assets/games/mini-golf-club/screenshot-gameplay-wide.png
- [Publisher splash image](references/splash.png): https://minigolfclub.io/assets/games/mini-golf-club/screenshot-splash-wide.png
- [Publisher cover](references/cover.jpg): https://minigolfclub.io/assets/games/mini-golf-club/ogimg.jpg

These were retrieved from the publisher page over verified HTTPS. The external Unity game was not played in this cloud browser; its certificate trust path prevented that session. These are explicitly publisher images, not Playgrid screenshots, and are not loaded by the production application.

All Playgrid geometry, textures, level layouts, UI and interaction code in this rebuild are original. No publisher game code, models, textures, branding, economy or level files were copied. The only added third-party runtime component is MIT-licensed Three.js, locally vendored with its license and checksum.
