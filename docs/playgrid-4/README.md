## What changed

The creator opens as a visual gallery of all 35 characters, with a large live preview, search, family filters, category buttons, color swatches and accessory artwork. Randomize, bounded Undo, character Reset, Save and classic-avatar fallback use the existing validated v3 configuration. The name field comes first; mobile uses a compact preview and scrollable gallery. Keyboard focus survives gallery rerenders; reduced-motion preferences disable the entrance animation.

Invites route first-time players through name/character setup and **Save & Join Party**. Returning players see their saved identity and **Confirm & Join**, with an edit option. Direct links, hashes and room-code joins share the deliberate join guard. Editing an invite does not allocate a seat. Refresh and Return to Game retain the existing session token and room code.

Draw & Guess uses a viewport-fitting 4:3 desktop canvas, a slim complete tool rail and persistent players/chat. Desktop expansion and global focus preserve the social rail; phone expansion retains its existing collapsible chat behavior. Pool, Golf, Battleship placement, Ludo and Property Tycoon receive separate desktop board/control layouts rather than a universal board cap.

Ads are centrally configured, disabled by default, labeled, consent-gated and limited to spacious visible desktop screens. No publisher IDs or external ad SDK are supplied. Navbar Return to Game retains the glowing lime treatment; the existing lower return card remains.

## Artwork: precise scope

All 35 existing SVG bases received a compatible lighting/material pass and have reusable composed default-look thumbnails. All 32 supporting characters received individual costume or robot construction details: eight humans, twelve animals, six fantasy characters and six robots. The three homepage-inspired anchors retain their original construction. Ember now has auburn hair, warm clothing and an uncovered focused face to distinguish it from Home Gamer. Character IDs, saved choices, accessory anchors and classic fallbacks are retained. The homepage illustration is untouched.

**This is a refinement of the existing illustrations, not 35 newly redrawn premium characters.** Existing silhouettes and most facial anatomy/accessory geometry remain. A stronger bespoke illustration pass—especially individual proportions, silhouettes and accessories—is still needed to meet the assignment's highest creative ambition. These screenshots expose that remaining gap for visual review instead of claiming that a shading pass is a full redraw.
