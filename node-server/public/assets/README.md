# Playgrid artwork

`hero-mascots.png` and `player-portraits.png` are original AI-generated illustrations created for this implementation using the owner's approved storyboard as the visual direction. They recreate the character types, palette, and styling; they are not extracted source artwork and are not pixel-identical to the storyboard. The portrait sprite contains four characters, with six hue variations retaining the existing 24 server avatar indices. Player accent colors retain the existing ten choices.

`draw-guess.svg`, `four-row.svg`, `coming-soon.svg`, the Playgrid mark, UI icons, confetti, and podium are original vector/CSS assets drawn for this implementation. No emoji or stock photographs are used as UI artwork.

Inter is self-hosted from the Google Fonts repository. Its SIL Open Font License is included in `fonts/OFL.txt`.
